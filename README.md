# Taskorium

A modern Android task management application built with Kotlin and Jetpack Compose.

> A personal Android project focused on modern application architecture, local persistence, REST API integration, authentication, synchronization, and background work.
## Features

- Create, update, and delete tasks
- Organize tasks by categories
- Search and filter tasks
- User authentication
- Local task persistence with Room
- Remote data synchronization through REST APIs
- Offline/local data handling
- Background synchronization with WorkManager
- Task reminders and notifications
- Soft deletion
- Reactive UI state management with StateFlow and SharedFlow
